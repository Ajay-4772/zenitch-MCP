## 2. Core Operational Principles

1. **Empirical Research Over Assumptions**: Every design decision is grounded in verified modern design patterns, web inspections, and official framework documentation.
2. **Visual Stun Factor Without Compromise**: Modern aesthetics (dark luxury, Swiss typography, kinetic motion, glassmorphism, bento layouts) are engineered without sacrificing accessibility, responsiveness, or frame rates.
3. **Progressive Disclosure**: Skills and deep documentation load on demand, preserving the model context window while retaining comprehensive depth.
4. **Zero Placeholder Policy**: No broken mockups or synthetic placeholders; production-ready SVG assets, generative art, and real content architecture only.
5. **Strict Motion & 3D Ethics**: Every animation and 3D scene has purpose, strictly honors `prefers-reduced-motion`, and avoids memory leaks or battery-draining render loops.
