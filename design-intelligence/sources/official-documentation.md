# Verified Official Documentation Sources & Reference Matrix

Date Audited: 2026-10-02  
Status: Verified Live & Operational

---

## 1. Frontend Frameworks & Standards
- **MDN Web Docs (Mozilla Developer Network)**:
  - URL: https://developer.mozilla.org/
  - Topics: Modern CSS Grid, Flexbox, WebGL API, WebGPU API, CSS Animations, Web Components.
- **W3C Web Accessibility Initiative (WAI)**:
  - URL: https://www.w3.org/WAI/standards-guidelines/wcag/
  - Standards: WCAG 2.2 Level AA/AAA, ARIA Authoring Practices Guide (APG).

---

## 2. Animation & Motion Engineering
- **Motion (formerly Framer Motion)**:
  - URL: https://motion.dev/
  - Scope: React motion components, gesture animations, layout transitions, spring physics.
- **GSAP (GreenSock Animation Platform)**:
  - URL: https://gsap.com/
  - Scope: High-performance timelines, ScrollTrigger, Flip plugin, SVG animation.
- **Lenis Smooth Scroll**:
  - URL: https://lenis.darkroom.engineering/
  - Scope: Modern, non-intrusive smooth scroll physics with native event preservation.

---

## 3. 3D Web & WebGL
- **Three.js**:
  - URL: https://threejs.org/
  - Scope: Scene graphs, PBR materials, cameras, GLTF/GLB loaders, post-processing.
- **React Three Fiber (R3F)**:
  - URL: https://r3f.docs.pmnd.rs/
  - Scope: Declarative Three.js in React, Fiber reconciler.
- **Drei**:
  - URL: https://drei.docs.pmnd.rs/
  - Scope: Battle-tested hooks, controls, geometries, and shader helpers for R3F.

---

## 4. UI Component Systems & Primitives
- **shadcn/ui**:
  - URL: https://ui.shadcn.com/
  - License: MIT
  - Scope: Copy-paste accessible components built on Radix Primitives and Tailwind CSS.
- **Aceternity UI**:
  - URL: https://ui.aceternity.com/
  - License: Free for personal/commercial use; MIT-compatible snippets.
  - Scope: Framer Motion animated backgrounds, 3D cards, text effects.
- **Magic UI**:
  - URL: https://magicui.design/
  - License: MIT
  - Scope: High-polish landing page animated components, infinite marquees, particle spheres.
